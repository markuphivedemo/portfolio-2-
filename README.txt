EDITORIAL PORTFOLIO — MarkupHive

Open index.html in a browser to preview.
Edit index.html for the name, biography, projects, experience, education, contact links, and image URLs.
Edit style.css to adjust colors and layout.
Replace the sample Unsplash image URLs with your own images or local assets.
Add resume.pdf beside index.html to enable the résumé download.
The template is a static site and can be deployed to GitHub Pages or any static host.
The sample images load from Unsplash and require an internet connection.
